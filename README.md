This is vulkan renderer based of vkguide.dev that uses SDL2 for window opening, fastgltf for loading GLTF files, and DearImGui for UI, but has been significantly expanded to handle updated fastgltf loading, 
phong illumination, and physical based rendering (PBR). Since it supports supports physical based rendering, it automatically supports hdr file loading, shadow mapping, normal mapping, cube mapping, emissive textures, and image based lighting.
